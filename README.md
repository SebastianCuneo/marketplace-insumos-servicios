# Marketplace Insumos y Servicios

Un marketplace para la compra y venta de insumos y servicios.

## Instalación

1. Instala las dependencias:
```bash
npm install
```

2. Ejecuta el proyecto en modo desarrollo:
```bash
npm start
```

3. Abre [http://localhost:3000](http://localhost:3000) para verlo en el navegador.

## Scripts Disponibles

- `npm start` - Ejecuta la aplicación en modo desarrollo
- `npm build` - Construye la aplicación para producción
- `npm test` - Ejecuta las pruebas
- `npm eject` - Expone la configuración de webpack (irreversible)

## Tecnologías Utilizadas

- React 18
- JavaScript
- CSS3
- HTML5
